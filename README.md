# Syntexchhub E-Commerce Store

## Project Description
This is a simple full-stack e-commerce store project.

## Technologies Used
- React
- Python FastAPI
- SQLite

## Main Features
- User registration and login
- View products
- Add products to a shopping cart
- Demo checkout
- View orders

## How to Run
Please refer to the project setup instructions and install the required dependencies before running the frontend and backend.
